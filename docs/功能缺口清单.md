# 刷题宝功能缺口清单

> 生成时间：2026-06-29
> 对比维度：① spec 设计承诺但未实现 ② 同类刷题软件常见但缺失 ③ 已有功能但深度不够

## 一、spec 承诺但未实现（10 项核心缺口）

### 1. 题干/选项中的图片渲染 ❌
- **spec 引用**：§4 "图片存储：题干/选项中的图片存到应用数据目录"
- **现状**：`ImportView.vue` 用 mammoth 转 HTML 后只取 `textContent`，图片信息全部丢弃；`ai.rs` 也未发送图片给视觉模型
- **影响**：含图示、公式截图、表格的题库（如医学/工科）完全不可用
- **建议**：
  1. mammoth 提取 `rawImages`，存到 `app_data/images/<bank_id>/`
  2. 题干用 markdown 引用 `![](images/xxx.png)`
  3. AI 模式调用视觉模型（GPT-4o / GLM-4V）发送图片+文本
- **工作量**：大

### 2. 模拟考试模式（限时计分）❌
- **spec 引用**：§5.2 "模式切换：顺序/随机/错题重练/模拟考试（限时计分）"
- **现状**：PracticeView 只有顺序/随机 2 个模式
- **建议**：
  1. 模式下拉加"模拟考试"
  2. 配置：题数（默认全卷）、时长（默认 60min）、是否乱序
  3. 顶部倒计时，到点自动交卷
  4. 交卷后显示得分、错题列表、用时统计
- **工作量**：中

### 3. 单题计时 ❌
- **spec 引用**：§5.2 "顶部：题库名、进度（12/100）、计时"
- **现状**：`duration_ms` 字段一直传 `null`（`PracticeView.vue:278`）
- **影响**：无法统计单题用时、做"用时排行"、识别慢题
- **建议**：QuestionCard 进入时启动计时，提交时记录 duration_ms，统计页展示
- **工作量**：小

### 4. 快捷键 ❌
- **spec 引用**：§5.2 "快捷键：1-4 选 ABCD，空格确认，←→ 翻页"
- **现状**：无任何 `@keyup` 监听
- **建议**：见优化清单 P1-9
- **工作量**：小

### 5. 错题本"已掌握" ❌
- **spec 引用**：§5.1 "错题本：可重练、标记已掌握"
- **现状**：DB 有 `status='pending'/'mastered'` 字段，前端无入口
- **建议**：见优化清单 P1-7
- **工作量**：中

### 6. 统计可视化 ❌
- **spec 引用**：§5.1 "统计页：正确率趋势、薄弱题型、用时分布"
- **现状**：StatsView 只有 3 个标量数字
- **建议**：见优化清单 P1-11
- **工作量**：大

### 7. 主题/字号设置 ❌
- **spec 引用**：§5.1 "设置：AI Key、OCR 引擎、Tesseract 路径、主题"
- **现状**：SettingsView 只有 AI Key 一节
- **建议**：见优化清单 P1-15
- **工作量**：中

### 8. .doc / PDF / 扫描件支持 ❌
- **spec 引用**：§3.1 ".doc：先用 LibreOffice headless 转 .docx"
- **现状**：仅 .docx，UI 不提示用户 .doc 不支持
- **建议**：检测系统 LibreOffice，调用 `soffice --headless --convert-to docx`；不支持时 UI 明确告知
- **工作量**：中

### 9. 重复导入去重 ❌
- **spec 引用**：§6 "重复导入：按题库名 + 题目哈希去重提示"
- **现状**：无任何去重逻辑，重复导入同一题库会入库重复题目
- **建议**：题干+选项做 SHA256 哈希存 `questions.hash` 字段，导入前查询命中则提示用户"跳过/覆盖/全部导入"
- **工作量**：中

### 10. 导入前自动备份 ❌
- **spec 引用**：§6 "数据备份：每次导入前自动备份数据库到 backups/，可回滚"
- **现状**：无任何备份
- **建议**：导入流程开始前 `cp shuati.db shuati.db.bak.{timestamp}`，保留最近 5 个，SettingsView 加"恢复备份"入口
- **工作量**：中

## 二、spec 部分实现（4 项深度不够）

### 11. OCR 未实际启用 △
- **spec 引用**：§2.1 "OCR：Tesseract（chi_sim + eng）"
- **现状**：`ocr.rs` 代码存在、`ocr_available()` 命令存在、SettingsView 显示"✓ Tesseract 可用"，但 `pipeline.rs:7` 注释"不再做 OCR"，流程根本不调用
- **建议**：要么真接入图片段落 OCR，要么删除死代码 + UI 提示"仅文本题"
- **工作量**：中

### 12. 填空/问答题自评 △
- **现状**：QuestionCard 第 39-40 行只有"答对/答错"自评按钮，无关键词匹配
- **建议**：
  1. 填空题：按 `answer` 数组的多个空格分别匹配（包含/正则）
  2. 问答题：调 AI 自动评分（可选）
  3. 提供"参考答案"对比视图
- **工作量**：中

### 13. 低置信度标红 △
- **spec 引用**：§3.4 "标记低置信度项标红"
- **现状**：`questions.confidence` 字段存在但 ImportReviewTable 完全未使用
- **建议**：confidence < 0.6 的行整行标红背景，加"⚠️"图标
- **工作量**：小

### 14. AI 模式下大文件分批 △
- **spec 引用**：§6 "大文件（>50 页）：分批 OCR，进度条反馈"
- **现状**：AI 模式按 30 题/块分批，但块数无上限，5 分钟硬超时可能截断大题库
- **建议**：根据 token 估算动态调整块大小；支持断点续传
- **工作量**：中

## 三、spec 未提但同类刷题软件常见（11 项扩展功能）

### 15. 题目标签 / 知识点分类 ❌
- **现状**：questions 表无 tags 字段，章节信息（已解析）也未持久化
- **建议**：
  1. 加 `tags TEXT`（JSON 数组）和 `chapter TEXT` 字段
  2. 导入时让用户标注章节/知识点
  3. 练习页加"按章节筛选"下拉
  4. 统计页加"薄弱知识点"维度
- **工作量**：中

### 16. 笔记功能 ❌
- **现状**：无
- **建议**：每题可加私人笔记（markdown），存新表 `notes(bank_id, question_id, content, updated_at)`，QuestionCard 加"📝 笔记"按钮
- **工作量**：中

### 17. 题目纠错 / 反馈 ❌
- **现状**：发现错题只能去校验页编辑（导入后无法编辑题目本身）
- **建议**：练习页加"举报错误"按钮，存 `reports` 表，题库管理页统一查看处理
- **工作量**：中

### 18. 学习计划 / 目标设定 ❌
- **现状**：无
- **建议**：题库页加"设置目标"，如"30 天刷完 500 题，正确率 80%"，每日打卡记录进度
- **工作量**：大

### 19. 每日打卡 / 学习日历 ❌
- **现状**：practice_records 有 practiced_at 但未做日历可视化
- **建议**：统计页加"近 30 天练习热力图"（类似 GitHub contribution），连续打卡奖励
- **工作量**：中

### 20. 题目搜索 ❌
- **现状**：见优化清单 P1-10
- **建议**：练习页加搜索框，按题干关键词跳转
- **工作量**：中

### 21. 题库导出 ❌
- **现状**：无
- **建议**：
  1. 导出为 JSON（含题目+答案+解析，可二次导入）
  2. 导出为 CSV（Excel 可打开）
  3. 导出错题本为 PDF / Word
- **工作量**：中

### 22. 跨设备同步 ❌
- **spec 引用**：§7.2 非目标"无云同步"
- **现状**：仅本地 SQLite
- **建议**：
  1. 短期：手动导出 `shuati.db` + 题库 JSON 包
  2. 长期：可选云同步（WebDAV / 坚果云 / 微云）
- **工作量**：大

### 23. 多端使用（移动端/网页）❌
- **spec 引用**：§7.2 非目标"无移动端"
- **现状**：仅 Tauri 桌面
- **建议**：长期可改造为 PWA 或 Tauri Mobile（iOS/Android）
- **工作量**：大

### 24. 题库市场 / 分享 ❌
- **spec 引用**：§7.2 非目标"无题库分享市场"
- **现状**：无
- **建议**：导出题库为 .qbpack 文件，社区分享导入
- **工作量**：大

### 25. AI 智能推荐 ❌
- **现状**：仅"AI 解析"单题，无智能出题
- **建议**：
  1. 基于错题记录，AI 推荐相似题/相关知识点题
  2. AI 生成相似题（变体练习）
  3. AI 总结个人薄弱点生成专属练习卷
- **工作量**：大

## 四、汇总与优先级建议

### 功能缺口分级

| 优先级 | 数量 | 代表项 |
|--------|------|--------|
| 🔴 高（影响核心使用） | 6 | 图片渲染、模拟考试、计时、快捷键、去重、备份 |
| 🟡 中（体验提升） | 9 | 错题已掌握、统计可视化、主题字号、OCR、标签、搜索、笔记、导出、章节筛选 |
| 🟢 低（扩展功能） | 10 | .doc/PDF、计划、打卡、同步、移动端、市场、AI 推荐、问答题评分、置信度标红、纠错 |

### 建议实施顺序

**第一波（1-2 周）— 补齐 spec 缺口**
1. 计时（小）→ 单题用时数据基础
2. 快捷键（小）→ 立即提升刷题效率
3. 错题已掌握（中）→ 错题本能闭环
4. 重复导入去重（中）→ 防止数据污染
5. 导入前自动备份（中）→ 数据安全兜底
6. 模拟考试模式（中）→ 完整练习闭环

**第二波（2-4 周）— 图片与统计**
1. 题干图片渲染（大）→ 解锁医学/工科题库
2. 统计可视化（大）→ 数据驱动学习
3. 主题/字号（中）→ 适配多场景
4. 标签/章节（中）→ 知识体系化

**第三波（1-2 月）— 扩展功能**
1. 笔记 / 搜索 / 题库导出
2. 学习计划 + 每日打卡
3. .doc/PDF 支持
4. AI 智能推荐（可选）

**第四波（长期）**
1. 跨设备同步
2. 移动端
3. 题库分享市场
